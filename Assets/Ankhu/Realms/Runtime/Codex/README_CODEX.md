# Anpu's Codex (journal UI)

The book Anpu gives Ankhu at the landing of Wernes. It starts blank and fills as he learns. Everything is built
from code (uGUI, no prefabs, no inspector wiring). Namespace `Ankhu.Realms`, assembly `Ankhu.Realms`.

## Files

| File | What it does |
| --- | --- |
| `CodexStore.cs` | The one `CodexJournal` of the game, persisted in PlayerPrefs (`ankhu.realms.codex`). |
| `CodexBook.cs` | The singleton: canvas (sort order 500), open book, input, open/close and page turn animation. |
| `CodexLayout.cs` | Pagination. Spell spread first, then every Lore, Clue and Memory entry in written order. |
| `CodexPages.cs` | Builds a page: papyrus, gutter, gold frieze and corners, folio, word cards, cartouches, entries. |
| `CodexToast.cs` | "Written in the codex" toasts, and the ceremonial toast for a word of power. |
| `CodexHud.cs` | Bottom right codex icon with the unread badge, and keycap hint chips. |
| `CodexArt.cs` | Inks, fonts, textures, glyph group and Egyptian numeral builders, a vertex gradient effect. |
| `CodexFx.cs` | Unread seal, ink drying fade, easing. |

Textures: `Assets/Ankhu/Realms/Art/Codex/Resources/RealmCodex/`, generated by
`Art/Codex/_tools/make_codex_art.py` (Pillow and numpy, fixed seeds). Run it again to regenerate.

## API

```csharp
// Bootstrap (any realm scene, once is enough, safe to call again):
CodexBook.Ensure();

// Writing (shows a toast, updates the badge, saves):
bool isNew = CodexStore.Write("word.open");

// New Game:
CodexStore.Reset();

// A scene loaded directly in development: write what the player would know, quietly (no toast, marked read):
CodexStore.EnsureEntries("lore.codex", "word.open", "word.name", "name.ankhu");

// Freezing gameplay:
CodexBook.OpenChanged += open => { /* pause the player, the camera, the timers */ };
bool open = CodexBook.IsOpen;   // true from the start of the open animation to the end of the close

// While the speech bubble has the keyboard (so typing "c" does not open the book):
CodexBook.InputBlocked = true;  // and false again when it closes

// Other hooks:
CodexBook.Open(); CodexBook.OpenAt("lore.ferry"); CodexBook.Close(); CodexBook.Toggle();
CodexBook.HudVisible = false;              // hide the HUD icon in cutscenes or menus
CodexBook.PageTurned += spread => { };     // paper sound
CodexToast.ToastShown += entry => { };     // scribble sound, or a gong for entry.Kind == CodexKind.Word
CodexToast.Suppressed = true;              // hold toasts during a cutscene, they show when cleared
CodexBook.EscapeConsumedFrame              // a pause menu should ignore Escape on this frame
CodexStore.Written / CodexStore.Changed    // events
```

The book does not touch `Time.timeScale`. It runs on unscaled time, so the game may pause however it likes.
While open it shows and unlocks the cursor, and restores the previous cursor state on close.

## Controls

| Action | Keyboard and mouse | Gamepad |
| --- | --- | --- |
| Open or close | Tab or C, or click the HUD icon | View (Select) |
| Close | Escape, or click outside the book | B |
| Turn pages | D, Right, E, Page Down / A, Left, Q, Page Up, mouse wheel, click a page corner | RB / LB, d-pad |
| Back to the words of power | Home | Y |

Hints under the book and on the toasts switch between keyboard and gamepad labels with the last device used.

## The book

* Spread 1 (pages 1 and 2) holds the spells. Every Word is a card: gold glyph group from `Signs`, the English
  name in Cinzel capitals, the transliteration in red ochre italic, the `Effect` line. Names sit in gold
  cartouches. Slots for words and names not yet learned (counted from `CodexCatalog`) show faint blank
  cartouches and ruled lines. If many words exist the cards go to two columns and then shrink to fit.
* From page 3 on, Lore, Clue and Memory entries flow in written order: a kind row (icon, kind, realm), a gold
  glyph heading, the title as a red rubric, the body in Cormorant italic with its first words in red. Long
  bodies split across pages ("TITLE, CONTINUED"). `Addenda` follow as ochre dotted lines.
* Memory entries show `Resources.Load<Texture2D>("RealmMemories/" + entry.Id)` if it exists (cover fit), or a
  sepia ink wash placeholder with the entry's glyphs.
* Unread entries carry a small gold seal. After a spread has been on screen for about 1.8 s, its entries are
  marked read and the seals fade. Unread entries appear like drying ink the first time they are shown.
* The book opens at the first unread entry, otherwise where the reader left off. A blank spread always follows
  the last written page.
* Folios: Egyptian numerals (strokes, heel bones, coils) with the Arabic number small beside them.

## Adding entries

Add a `yield return Word(...)`, `Name(...)`, `Lore(...)`, `Clue(...)` or `Memory(...)` in
`Assets/Ankhu/Realms/Core/Content/CodexContent.cs`, then call `CodexStore.Write("your.id")` where Ankhu learns
it. `Signs` are Gardiner codes separated by spaces. Codes without a texture in `GlyphAtlas` are skipped. For a
painted memory, put a texture at `Resources/RealmMemories/<entry id>.png` (any Resources folder).
Nothing in the UI needs to change: pagination is measured at open time.

## Dependencies

`GlyphAtlas` (Get, GetGlow, Cartouche, Has, InkRect, Aspect) and `GlyphTable` from `Runtime/Magic`,
`RealmFonts` from `Runtime/Director`, `UiKit` from `Ankhu.Opening`, `Ankhu.Realms.Core` for the data.

## Untested (nobody could press Play here)

Compiled offline against Unity 6 reference assemblies (Editor and Player defines, 0 errors, 0 warnings).
Everything below is unverified in a running game:

* Overall look: sizes, spacing, colour balance of gold on papyrus, and whether text fits the word cards at
  1080p. The effect line uses best fit (14 to 19 pt) to absorb longer lines.
* Text measuring for pagination uses `TextGenerator` at scale 1 with a 3 percent margin. If text renders
  wider at odd resolutions, a line may run past the bottom margin. Raise the margin in `CodexLayout.Measure`.
* Italic comes from `FontStyle.Italic` on Cormorant Garamond SemiBold, which Unity synthesises (there is no
  italic face in the project). Adding CormorantGaramond-Italic and loading it would look better.
* The open, fan and page turn animation timing, the shadow sweep, and the corner curl hover.
* Gamepad device detection, and Tab or Escape conflicting with other systems (check `EscapeConsumedFrame`).
* PlayerPrefs persistence across sessions, and `Reset()` from a New Game flow.
* Textures import with Unity defaults (no .meta files shipped). Wrap mode and filtering are set at runtime.
